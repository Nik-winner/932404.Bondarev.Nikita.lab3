## Выполненные задачи
- Основной стиль вынесен во внешний файл css/lab3.css.
- Использованы CSS-переменные в псевдоклассе :root для централизованного хранения основных цветов и шрифтов.
- Реализовано навигационное меню и карточки «Текущие акции» с помощью Flexbox (горизонтальное адаптивное меню с flex-wrap, карточки выстраиваются в ряд и адаптируются по ширине).
- Реализован блок «Роли в команде» с помощью CSS Grid (сетка из 3 колонок на десктопе, адаптирующаяся до 2 и 1 колонки на меньших экранах).
- Добавлены медиа-запросы (@media) для планшетов (≤1024px) и мобильных устройств (≤768px, ≤480px), обеспечивающие корректное отображение и полное отсутствие       горизонтальной прокрутки (за счет box-sizing: border-box и overflow-x: hidden).
Применены семантически верные теги HTML5 для улучшения доступности и структуры: <nav>, <main>, <section>, <article>, <aside>, <header>, <footer>, <time>.
Обеспечена контрастность текста не менее 4.5:1 (соответствие стандартам доступности WCAG) за счет использования цветов #212121 и #C62828 на светлом фоне #FFFFFF / #F9F9F9.
- В качестве иконок использованы эмодзи, стилизованные через CSS (круглая подложка, центрирование и плавная анимация увеличения при :hover).
- Реализованы интерактивные состояния элементов: :hover, :active, :focus, :visited для навигационных ссылок, полей ввода и кнопки.
